Before you write

  • Search the open issues first. If yours is there, add a thumbs up or a comment.
  • Check the questions and fixes.
  • One problem per report makes it faster to fix.

What helps

App version
Firewall, Settings, at the bottom.
Phone model and Android version
Android settings, About phone.
Which screen
Apps, Activity, Domains, Trackers, Settings, an app's page, the tile, the widget or a notification.
The app and the domain
Which app misbehaves and, from Activity, the name it looked up.
Steps
What you did, one step per line.

Issues on GitHub are public. Your activity log shows which sites you visit, so crop screenshots and leave out anything private.
